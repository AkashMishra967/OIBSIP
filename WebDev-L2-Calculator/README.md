# Calculator Web Application

## About the Project
This is a simple and responsive Calculator Web Application developed using HTML, CSS, and JavaScript.

## Features
- Addition, Subtraction, Multiplication and Division
- Decimal number support
- Clear (AC) button
- Delete (DEL) button
- Operator chaining
- Division by zero error handling
- Responsive calculator layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run index.html using Live Server.
