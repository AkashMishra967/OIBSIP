# TaskFlow - To-Do Web App

## About
TaskFlow is a responsive To-Do Web Application that helps users organize and manage their daily tasks.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Separate pending and completed task lists
- Total, pending and completed task counters
- Local Storage support
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Clone or download this repository.
2. Open the WebDev-L2-TodoApp folder.
3. Open index.html using Live Server.
